⚙️ Technology

How On-Device AI Works

📥

1. One-Time Download

User downloads a quantized Gemma 2B LLM model (≈1.35 GB) directly to their device. Done once, runs forever — no subscriptions.

🔄

2. Local Inference

All AI processing runs on the device's GPU/CPU via MediaPipe LLM Inference — no network packets, no API calls, no external services.

🗑️

3. Session Memory Only

Conversations exist only in active memory. Nothing is persisted to disk or cloud. Closing the chat erases all context permanently.

🔒
Privacy Guarantee: Mathematical Certainty

Since the model runs entirely locally and no network connections are made during inference, it is technically impossible for your conversation data to leave your device. This is not a policy — it's physics.
